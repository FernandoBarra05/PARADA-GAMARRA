# Parada & Gamarra — demo web

Sitio web estático de demostración, responsive y preparado para GitHub Pages. No requiere servidor, framework ni contratación de hosting.

## Publicación en GitHub Pages
1. Crear un repositorio en GitHub (por ejemplo, `parada-gamarra-demo`).
2. Subir **todo el contenido** de esta carpeta al nivel raíz: `index.html`, `styles.css`, `script.js` y `assets/`.
3. En **Settings → Pages → Build and deployment**, elegir **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guardar.
4. Abrir el enlace que GitHub muestre en la sección Pages.

## Aspectos por confirmar antes de publicar la web oficial
- Las imágenes `despacho-conceptual.webp` y `equipo-ilustrativo.webp` fueron creadas como **recursos conceptuales**. La escena de dos profesionales **no representa a José Luis y Patricia**. No presentarla como fotografía real de los socios.
- Sustituir la imagen conceptual por fotografías auténticas del estudio y de ambos socios cuando se cuente con permisos.
- Completar/validar la biografía de Patricia y cualquier mención de credenciales.
- El dato de una tasa de éxito del 96% **no se utiliza** hasta que el estudio verifique su cálculo y sustento.
- Confirmar domicilio, horario, teléfono y redes sociales; el prototipo no inventa estos datos.
- El formulario **abre un correo con `mailto:`**, sin almacenar ni enviar información desde un servidor. Es adecuado para el demo, pero en producción conviene integrar un servicio de formularios o backend real.
- Las imágenes, textos y disposición constituyen una propuesta visual editable para aprobación.
